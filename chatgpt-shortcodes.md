# ChatGPT Prompt Shortcodes

> **Note:** Yeh ChatGPT ke official commands nahi hain. Yeh sirf short instructions hain jinka matlab ChatGPT samajh leta hai aur us hisaab se jawab deta hai. Behtar result ke liye shortcode ke saath thoda context zaroor likhein.

## Text / Explanation ke liye

| Shortcode | Kya karta hai |
|---|---|
| `/ELI5` | Aise samjhao jaise 5 saal ke bachche ko samjha rahe ho |
| `/TLDR` | Lambe text ka chhota summary |
| `/BRIEFLY` | Chhota aur to-the-point jawab |
| `/STEP-BY-STEP` | Har cheez step-by-step samjhana |
| `/EXPLAIN LIKE A TEACHER` | Teacher ki tarah detail mein samjhana |
| `/NO JARGON` | Bina technical shabdon ke simple bhasha |
| `/EXAMPLES` | Examples ke saath samjhana |
| `/PROS-CONS` | Fayde aur nuksaan ki list |
| `/COMPARE` | Do cheezon ki tulna (comparison) |

## Format ke liye

| Shortcode | Kya karta hai |
|---|---|
| `/TABLE` | Jawab table mein |
| `/CHECKLIST` | Checklist ke roop mein |
| `/BULLETS` | Bullet points mein |
| `/MINDMAP` | Mind map jaisa structure |
| `/FLASHCARDS` | Padhai ke liye flashcards |
| `/QUIZ` | Topic par quiz banana |
| `/NOTES` | Short study notes |

## Image / Style ke liye

| Shortcode | Kya karta hai |
|---|---|
| `/HANDWRITTEN NOTE` | Notes ko handwritten (kaagaz par likhe jaise) image mein banana |
| `/WHITEBOARD` | Whiteboard par likha hua explanation |
| `/INFOGRAPHIC` | Topic ka infographic |
| `/DIAGRAM` | Diagram ya flowchart |
| `/POSTER` | Poster design |
| `/SKETCH` | Pencil sketch style |

## Writing / Role ke liye

| Shortcode | Kya karta hai |
|---|---|
| `/ACT AS [role]` | Kisi role jaise teacher, doctor, interviewer ki tarah jawab |
| `/REWRITE` | Text ko dobara behtar likhna |
| `/FORMAL`, `/CASUAL` | Tone badalna |
| `/HUMANIZE` | Text ko natural aur insaan jaisa banana |
| `/SWOT` | SWOT analysis |
| `/BRAINSTORM` | Naye ideas ki list |

## Use kaise karein

Shortcode ke baad apna topic likhein:

```
/HANDWRITTEN NOTE Photosynthesis par class 10 ke notes banao
```

```
/ELI5 Blockchain kya hai?
```

```
/TABLE /COMPARE iPhone vs Android
```

## Tips

- Ek saath do shortcodes bhi use kar sakte hain, jaise `/STEP-BY-STEP /EXAMPLES`.
- Handwritten note, poster, sketch jaise image wale shortcodes ke liye ChatGPT mein image generation available hona chahiye, warna woh sirf text mein jawab dega.
- Agar result pasand na aaye, to shortcode ke saath extra detail likhein (jaise class, language, length).
